# Status

Check `python3 --version` once; if it fails, try `python` (only if it reports 3.x). If neither works, say so and read `cards/STATUS.md` by hand.

Run `python3 cards/cards.py status` and `check` from the project root. Lead with the wave line and the needs-you count, then what is worth reading (cards in review, cards closed in the last hour, their Outputs), then the newest learned lines. Start and review nothing here. No `cards/` directory: say so and offer the start skill.
